DOVE MANGIARE — VERSIONE CON FOTO

1) Sostituisci il file:
   app/dove-mangiare/page.tsx
   con quello contenuto in questo pacchetto.

2) Copia l'intera cartella:
   public/images/dove-mangiare/
   dentro il progetto, mantenendo esattamente lo stesso percorso.

3) Esegui il commit/push su GitHub come fai normalmente.
   Vercel dovrebbe creare automaticamente il nuovo deployment.

Le 42 immagini sono state convertite in WebP e ottimizzate per il web.
Il codice usa next/image, lazy loading automatico e sizes responsive.
Le immagini hanno alt text descrittivi; in fase di traduzione potranno essere localizzati nelle altre lingue.

Nota: questa versione parte dalla V6 con layout mobile a fisarmonica, desktop sempre aperto,
indicazioni alimentari, avviso prenotazione e pulizia degli hash nell'URL.
